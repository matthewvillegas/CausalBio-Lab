# CausalBio Lab demo script

An actual [72-second production walkthrough](assets/demo-walkthrough.mp4) and [text transcript](demo-transcript.md) are included. It uses cached evidence, normal timing, on-screen captions, and no audio. The plan below is for an optional narrated replacement; its suggested 60-second timing is not the duration of the included recording.

## Recording setup

Use the current production application after completing the [setup and checks](../README.md). Record a 1440 × 1000 browser viewport in light mode, at 100% browser zoom, with notifications and unrelated tabs hidden. Keep the pointer visible. Use application content rather than terminal logs or a scrolling list of technologies.

Before recording, run “What mechanisms influence tendon recovery?” once and inspect its sources, context, and limitations. A later run may use the validated cache; say so. Keep a curated memory investigation open in a second tab for the numerical section. Run its baseline comparison before recording if the final segment will show an existing result.

This is an edited walkthrough, not a benchmark. Leave a brief real loading stage visible. If retrieval takes longer than the allotted segment, cut the wait with an explicit “Research completed; waiting time shortened” caption. Do not speed up a search without labeling the edit. A saved result should be labeled “Saved investigation”; a cached response should not be described as a fresh search.

## Recommended 60-second sequence

| Time    | Exact screen sequence                                                                                                                                               | Suggested narration                                                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0–08 s  | Investigate page → enter “What mechanisms influence tendon recovery?” → **Investigate** → review interpretation → **Continue**.                                     | “CausalBio organizes a biological question into inspectable evidence and possible mechanisms.”                                                         |
| 08–20 s | Show the real loading stage, then **Research summary** and **Possible mechanisms**. Keep source/cache status visible.                                               | “This bounded search uses public scientific sources. These groups are provisional, and different studies may describe different organisms or tissues.” |
| 20–32 s | Select the first **Explore mechanism** action. Scroll to **Focused pathway** and its caption.                                                                       | “The focused view connects this group to its supporting records. A source connection is not proof of a causal pathway.”                                |
| 32–43 s | Click a numbered citation. Pause on the title, passage, context, identifier, and retrieval date. Close with **Close evidence** or Escape.                           | “Each extract retains its source. Missing context stays unknown, so I can inspect what the result does and does not support.”                          |
| 43–52 s | Switch to the prepared curated memory tab, or choose **New investigation** → **Long-term memory retention** → **Continue**. Open a mechanism.                       | “Two curated examples go deeper, with explicit relationships, supporting evidence, and competing explanations.”                                        |
| 52–60 s | **Advanced analysis** → **Pathway simulation** → show the completed baseline comparison and model warning. End on a short factual title card linking to validation. | “Selected models support educational simulations. Numerical and software tests check their stated behavior; they do not establish biological truth.”   |

If the first search has not finished by 20 seconds, use a 75–90 second version or the labeled wait cut. Do not squeeze all of the graph, Petri, HMC, peptide, and export tools into one minute.

## Optional 20-second extension

From the curated result choose **Uncertainty analysis**, then **Run uncertainty demonstration**. Show the synthetic-data notice, posterior estimates, and one diagnostic explanation. Narration: “This separate HMC demonstration estimates two parameters from synthetic data with a known analytic reference. It tests numerical inference, not a treatment or an arbitrary biological question.”

Finish on the [validation record](validation.md), using the counts from the actual release run. Avoid describing coverage as proof of correctness.

## Before publishing

- Review every visible source title, question, saved-session name, and browser address for private information.
- Preserve warnings, provisional labels, and the simulation's declared assumptions in the frame.
- Do not show credentials, local filesystem paths, personal browser profiles, terminal history, or real patient information.
- Do not claim exhaustive research, independent scientific validation, measured user adoption, or an instant live result.
- Add captions and a text transcript. Review the exported video for legibility at a smaller embedded size.
- Upload only after review. Replace the README's demo link with the actual hosted URL; no URL is supplied until it exists.

The walkthrough is a product demonstration. First-person narration about authorship or learning must accurately describe your own contribution and experience.
