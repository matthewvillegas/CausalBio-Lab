The connecting theme can be **mathematics and computation applied to scientific and physical systems**. Each project should earn that description through a concrete model, an inspectable implementation, and an honest account of what was tested.

| Project             | Supplied focus                                                                          | Role in the portfolio                                                                              |
| ------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| CausalBio Lab       | Computational biology, causal/evidence graphs, synthetic Bayesian inference, simulation | Organizing uncertain scientific evidence and keeping model assumptions explicit.                   |
| BGCE                | Mathematical modeling, dynamical systems, statistical fitting, simulation               | A complementary modeling and parameter-fitting story, if supported by that project's own evidence. |
| MonumentStudio      | Parametric design, geometry, engineering software                                       | Turning geometric constraints into usable design tools.                                            |
| Robot Arm Simulator | Kinematics, controls, robotics, numerical methods                                       | Connecting mathematical motion models to an interactive system.                                    |
| Thermal Controls    | Heat transfer, fluids, PID, optimization                                                | Applying physical models and control choices to a thermal problem.                                 |

Present each project with the same short sequence: problem → representation/model → implementation decision → validation → limitation → next step. Avoid repeating a long technology list. CausalBio's distinct contribution to that story is the relationship between evidence, mechanism structure, numerical assumptions, and uncertainty.

Do not imply that a listed project has achieved hardware deployment, experimental calibration, formal course mastery, or a successful optimization unless its own record supports that claim. Likewise, the CausalBio HMC example should remain explicitly synthetic when discussed beside other modeling projects.

Before using this framing, choose one decision from each project that you can explain and one result you can reproduce. Link to its own evidence rather than transferring CausalBio's test counts or validation claims to the rest of the portfolio.
