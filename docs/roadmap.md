# Roadmap

CausalBio already supports curated and provisional research, live source adapters, local saved sessions, reports, graph analysis, Petri/ODE models, and a separate synthetic HMC demonstration. These are implemented capabilities, not promises of comprehensive scientific coverage. Current verification is recorded in [validation](validation.md).

## Near term

- Improve study-context extraction and mechanism explanations while retaining exact citations and unknown fields. Evaluate failures involving methods-only sentences, species differences, and mixed tissue contexts.
- Make dense graph layouts easier to read and keep the textual alternative complete. Observe unfamiliar users completing a question-to-source workflow before adding more controls.
- Extend accessibility and browser validation beyond the current Chromium and sampled checks, including screen readers and independently observed keyboard use.

## Research infrastructure

- Improve explicit curation, review history, licensing and retraction checks, and the handling of contradictory studies. Retrieval must remain separate from promotion into trusted assertions.
- Add a scientific source only when its permitted use, context fields, retrieval boundaries, fixtures and failure behavior meet the existing evidence standard. More sources alone do not establish better conclusions.
- Strengthen study-context evaluations and reproducibility records. Treat any hosted multi-user deployment as separate work requiring authentication, isolation, retention controls, and a deployment security review.

## Longer term

- Develop deeper domain packs with documented competing mechanisms and independent domain-expert review.
- Add numerical biological models only when data, units, assumptions, identifiability and recovery checks justify them. General literature retrieval is not sufficient to define a likelihood or calibrated dynamics.
- Broaden independent scientific and usability review before making stronger claims about evidence quality or user comprehension.

No dates or expert participation are promised. The roadmap excludes autonomous diagnosis, prescribing, dosing, synthesis, procurement, and arbitrary biological posterior inference. A future model or inference backend needs its own validation; the current synthetic HMC result cannot supply that validation by analogy.
